# Assets

## Add your picture
1. Save your photo as **profile.jpg** inside `assets/images/`
   (full path: `assets/images/profile.jpg`).
2. Best results: portrait orientation (about 4:5), at least 800 x 1000 px, under 500 KB.
3. Refresh the page. Until the file exists, the site shows `placeholder.svg`.

Your photo appears on the front of the student ID badge in the hero.

Using a different file name or type (for example `me.png`)? Change the
`src="assets/images/profile.jpg"` line in `index.html`.
